# ORACLE Development Roadmap

This roadmap separates shipped code from intended capabilities. A phase is complete only after implementation, tests, documentation, and CI evidence exist.

| Phase | Scope | Status |
|---|---|---|
| 1. Foundation | Graph model, deterministic simulation, REST API, persistence, starter UI, containers | Initial baseline present; needs deeper validation |
| 2. Enterprise identity | OIDC/SSO, RBAC, tenant isolation, secure sessions | Planned |
| 3. Governance | Audit trail, retention, data export, policy controls | Planned |
| 4. Observability | OpenTelemetry traces/metrics, telemetry ingestion, health signals | Planned |
| 5. Digital twin evolution | Temporal topology, scenario comparison, capacity models | Planned |
| 6. AI assistance | Optional provider integration, grounded explanations, human review | Planned |
| 7. Web console | Topology visualization, scenario builder, history, administration | Starter only |
| 8. Production readiness | Threat-model closure, load/security tests, SBOM, signed releases, backup/restore | Planned |

Do not interpret a roadmap item as an existing feature.
